# XAU Strategy Researcher Pro v2.2 — Modular Architecture

## Rule
v2.1 remains the reference implementation. v2.2 is built incrementally; no module is allowed to silently change research semantics.

## Current extraction (Phase 1)

- `researcher/config.py` — central research configuration
- `researcher/logger.py` — thread-safe copyable log sink
- `researcher/utils.py` — shared helpers
- `researcher/mt5_connector.py` — MT5 initialization, terminal/account/symbol diagnostics; no order API
- `researcher/data_loader.py` — isolated historical-data boundary with chunk/retry loading
- `researcher/indicators.py` — pure indicator calculations
- `researcher/metrics.py` — pure performance metrics
- `core/` — backtest, strategy generation, risk and ranking will be extracted next
- `validation/` — train/test, OOS, walk-forward, Monte Carlo and robustness will be added here
- `exporters/` — CSV/JSON/trades/strategy rules
- `gui/` — status, controls, progress and log panel

## Dependency direction

GUI -> Research Engine -> Data/Indicators -> MT5 connector

Backtest must not import GUI. Indicators must not import MT5. Metrics must not import GUI or MT5.

## Safety rule
The research application is read-only with respect to MT5 trading. No `order_send`, position opening, modification or closing API belongs in this project.

## Migration strategy

1. Extract one responsibility.
2. Add a small module-level API.
3. Compare output against v2.1.
4. Only then remove the duplicate implementation from the monolith.
5. Keep v2.1 untouched as the reference until v2.2 passes parity tests.
